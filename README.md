# Cake — v0.71

Fillings are **78% thicker**: `FILL_T` 0.09 → 0.16 world units. Constant whatever the count; the
sponge layers shrink to make room, so a tier's height is unchanged. Applies everywhere the layer
scheme is used — the stack, the cut ends, the painted bases under a message or a scrape.

With three fillings on the shallowest Classic (0.6 tall) the sponge layers get thin (~0.03); the
shape slider's height will want to come up a step or two for that combination.
